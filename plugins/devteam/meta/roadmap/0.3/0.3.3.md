## 3. The work

Seven steps. Each is committed on its own, with `run_controls` green and
`check_plugin` clean, so that a rotation can fall between any two. In each:

- the planted case comes out as expected before the real result is believed
  (P-35b);
- every new assertion is shown to fail on a mutant of a copy of the whole
  plugin (`mutants.py`);
- the commit body names the register rows it closes (the cycle README's §9);
- the documents are brought level for what the step changes — CHECKS.md's
  rows, FORMATS, the templates, and the skill text that describes it. A class
  with no CHECKS.md row fails the plugin (`unruled-finding`), and a skill that
  describes the old parse is a second home, now wrong (P-34);
- every example the step adds or changes in a document is executed as written
  in a scratch project, in `.internal/scratch/0.3.3/examples_3_n.py`, with its
  output kept beside it — the owner's rule.
