## Findings

### §1's premise was wrong in the tree, and the finding is better than the one I first wrote

§1 opens *"Every core subcycle this cycle shipped is `DONE` and in `../done/`"*.
Only `0.2.0.md` was. **0.2.1 through 0.2.7 all read `DONE` and all sat in
`0.2/`**, so `ls 0.2/` listed seven finished subcycles and stated the exact
opposite of the property the convention exists to provide.

I first filed this as *"§1 assumes something untrue of the tree"*, having
grepped `0.2/README.md` and `done/README.md` and found nothing about moving
files. **`_s7` found the rule one directory up** — `meta/roadmap/README.md`:
*"When a subcycle reaches `DONE`, move its file to `done/`. `ls 0.2/` is then
what remains; `ls done/` is what happened."* §1 invented nothing. The finding
is *the convention exists and nothing enforces it*, and six consecutive
sessions skipped it while each was closing a subcycle — which is exactly when
a rule that lives only in a document goes unread.

Now three finding classes in `check_plugin`: `stranded-done-subcycle`,
`undone-subcycle-in-done`, and `subcycle-without-state` — the third because
without it the pair is defeated by leaving the state word out, which is the
exempted-and-unwatched shape this repository has now recorded four times.
`STOPPED` deliberately does not move; a check that swept every finished-looking
file into `done/` would enforce a rule nobody wrote, and that is a
false-positive control rather than a comment.

### The release gate was flaky, and said the wrong thing when it failed

`run_controls.py` went red on this session's first run and green on the next
four. `_s7` had run it **seven times** closing 0.2.7 and never seen a red, so
the rate is one in eight known runs across two sessions — and seven consecutive
greens is exactly the sample size that makes an operator trust a suite.

`fp-dns-resolves` asked the live network a question, and `getent` exits 2 for
"name not found", so a resolver blip was indistinguishable from the sandbox
breaking L-4. **The first fix attempted was to replace it with a namespace
identity check — which would have been this cycle's ninth instrument answering
an adjacent question**, because 0.2.1 built the case to catch a *dangling
`/etc/resolv.conf` symlink*, not to assert the namespace. Reading 0.2.1 §3.2
before editing is what caught it. The halves are now split: a structural case
that reads the file and always runs, and the live lookup, which runs only when
the host resolves the same name first and prints a skip saying why.

The second defect is sharper. `verdict()` reported `stderr.strip()[:200]` — the
**first** 200 characters of a stream whose first two lines are `cmd_run`'s
progress. **Every ALLOWED-case failure in a 71-case suite displayed a success
message where its reason belonged.** The red above announced itself as
`command written to meta/cmd.sh (3 argv elements)`.

### One marker meant "do not ship this" and "this is the required schema"

`setup.py` strips `<!-- example:begin -->` blocks; `check_trace.template_names()`
reads the **same** blocks to learn which rows a charter must have. The charter's
entire constraints table was inside one, so a scaffolded charter carried three
paragraphs on how to write a constraint row and **no table to write one into** —
no `Test command`, no `Budget ceiling`, no `Containment` — while
`setup/SKILL.md`, `onboard/SKILL.md` and `FORMATS.md` all told the reader to
write into it. All three green, because nothing compares a template's shipped
form against the documents describing it.

**Removing the markers fixed the ship and disarmed the check**, and the commit
that did it shipped RED: `run_controls.py` printed `FAILED: test_check_trace.py`
in plain sight, but it had been invoked as `run_controls.py | tail -3 && … &&
git commit`, and a pipeline exits with the status of its last command. `tail`
succeeded. The text was on screen and the exit code lied.

The hypothesis that the wrapping protected `template-ships-a-finding` was
**tested and false** — `check_refs` on a fresh scaffold is clean with the full
table present. The fix is two named markers, not a special case.

### The end-to-end walk, and what it found

A slugify library the pipeline had not written: `git init`, `setup`, two
interview questions, two requirements, one task, one step dispatched headless
at width 1.

**The first promotion was refused by build artifacts the step's own verification
command created** — `promote-uncommitted` naming two `.pyc` files. That is F-37
one whole cycle after `STACK_IGNORES` was built to prevent it, and worse: F-37
made a tree dirty, P-44 makes the finished step not land. `setup` keyed its
ignore lines on `detect()`, which requires a manifest, and this project is a
directory of `.py` files with a green suite and no manifest. `artifact_stack()`
splits the weaker question — *will this tree grow `__pycache__/`* — from the
stronger one `detect()` rightly insists on.

**`budget.json` named the model that did 3% of the work.** The field was
`next(iter(result["modelUsage"]))`, an arbitrary dict key:

```
claude-haiku-4-5-20251001 :    33,619 tokens   <- what was reported
claude-sonnet-5           : 1,066,326 tokens   <- what ran
```

`model-mismatch` is deliberately **not** advisory, so the check that exists to
catch a worker off its band was firing a **blocking** false positive on every
correct dispatch — on the happy path, which is how a check gets switched off.

**And one thing that is not a defect.** The worker tried to append its own
REPORT block to `devteam/tasks/T-1.md`, was refused because `devteam/` is
protected and outside its scope, and **reported the refusal rather than routing
around it** (P-39). L-6's early-warning half, observed live.

### A charter row that reads correctly to a human silently disarmed the guard

`Protected paths` was written as prose with a comma in it. The guard splits that
cell on commas and strips backticks, so it resolved two non-paths and protected
**nothing** — a write into `devteam/` was allowed, silently. Rewritten as a bare
path list, the same write is refused and a write inside the declared scope is
allowed, so the mechanism is sound and the cell format is load-bearing.

**Second instance of a shape the `setup` skill already warns about** for the
unexpanded-variable case: *a test written the natural way passes silently and
looks exactly like a guard that is not installed*. Queued as CONSOLIDATION N-4
with its trigger already fired; not built here, because this is a release.
